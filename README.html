Tools

To develop/run this webapp, you'll need the following tools:

  1. Python (3.8+)
    • The makefile will setup the venvs and install the requirements so you don't have to pollute your environment or manage them yourself.
  2. GNU Make
    • On macos, whatever comes with the xcode tools is fine.
    • On linux, just install a gnu make (you probably already have it).
    • On windows, grab it from here.
      • It's old af but it works fine.
  3. tsc (TypeScript Compiler)
    1. See here
    2. There's other janky ways to get tsc without node or npm, but I am not going to list them here.

Running Locally

If you have the above tools installed, you can just do make run and you'll get a server running. You can then visit it at http://localhost:5000. The first time you run the server it will create an empty database.

Make will be called whenever you visit a page. TypeScript is the slowest part, so you might want to execute it in watch mode so that it recompiles the typescript whenever you save.

For the stand-alone demo page, do make Generated/demo.html then open that file in a browser. If you have the server running you can also go to http://localhost:5000/demos/dungeon.html, which will rebuild it when you visit that url.

In DEV mode, static assets are served by the running webserver.

The AppConfig

This is just a simple python file that is imported. Make will generate one when do make run or you can do make appconfig.py yourself. See defaultconfig.py.

The values are pretty self explanatory.

Running on a Server

Put a reverse proxy like nginx in front of this so it can handle stuff like TLS and serving static files.

I use the makefile server.mak to run the server.

Bug Tracking

Bugs are tracked locally in the repo itself in the Bugs folder. The bugs are human-readable, but you will probably want to use the local web UI to view and manage them. You can do so with make bug.

Generally, you should resolve the bug in the same commit that resolves it.
